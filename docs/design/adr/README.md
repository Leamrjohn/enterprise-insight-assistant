# 架构决定记录（ADR）

ADR（Architecture Decision Record，架构决定记录）：一个重要的技术决定写一份，说明当时为什么这样选。决定改了就新写一份并在旧的里标“已被 ADR-NNNN 取代”，不改写旧结论。

**文件名：** `NNNN-简短标题.md`，编号递增。

**模板：**

```markdown
# ADR-NNNN 标题

**状态：** 提议 / 已决定 / 已被 ADR-NNNN 取代
**日期：** YYYY-MM-DD
**范围：** 影响哪些工单或模块

## 1. 背景
## 2. 选项（每个写优点、缺点）
## 3. 决定
## 4. 后果（变好什么、代价是什么、怎么回退）
```
